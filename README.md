# CDC

**Live site: [vladmartiro.github.io/CDC](https://vladmartiro.github.io/CDC/)**

This is our submission to the **CDC (Carolina Data Challenge)**, hosted by UNC Chapel Hill.
It was written in **September 2026**. All team members are **first-year PhD students at the UNC School of
Information and Library Science (SILS)**.

The project estimates a college graduate's chance of being **unemployed, NEET (not in education,
employment, or training), or underemployed** around age 24, based on their major, demographics, and state.
It then turns those estimates into an interactive website with an odds calculator, charts, and a
decision game.

For run order, variable definitions, model results, and full references, see
**[analyses/README.md](analyses/README.md)**.

## Repository layout

```
analyses/   Python scripts and notebooks (data download, modeling, charts)
config/     indicators.yaml: World Bank indicator list used by fetch_worldbank.py
data/       Input data and generated outputs (some large files are not committed, see below)
frontend/   Angular website, deployed to GitHub Pages
```

## Data

| Source | What we use it for | Files in `data/` |
|---|---|---|
| [US Census ACS 1-year PUMS](https://www.census.gov/programs-surveys/acs/microdata.html) (2019, 2021–2023) | Main modeling data: graduates aged 22–27 with a bachelor's degree or higher | `pums_grads.parquet` *(generated by `fetch_pums.py`, not committed)* |
| [Census CPS ASEC 2026](https://www.census.gov/data/datasets/time-series/demo/cps/cps-asec.html) | Exploratory NEET / unemployment analysis for ages 16–24 | `pppub26.csv`, `ffpub26.csv`, `hhpub26.csv` *(download by hand, not committed)* |
| [BLS Employment Projections, Table 1.2](https://www.bls.gov/emp/tables.htm) | Typical entry education per occupation, used to define underemployment | `occupation.xlsx` *(downloaded by hand)* |
| [World Bank WDI / EdStats](https://api.worldbank.org/v2) | NEET and youth unemployment across 35 countries of the Americas, plus USA trends | `worldbank_panel.csv`, `worldbank_long.csv`, `worldbank_indicators.csv`, `worldbank_coverage.csv`, `Develop_data.csv`, `Develop_metadata.csv`, `WD_USA_NEET.csv` *(not committed)* |
| [Eloundou et al. (2023), GPTs are GPTs](https://github.com/openai/GPTs-are-GPTs) | AI exposure score per occupation | `ai_exposure_occ_level.csv` (input), `ai_exposure_by_major.csv` (output) |
| Strada & Burning Glass Institute (2024), *Talent Disrupted* | Underemployment with vs. without an internship, by field | `internship_by_field.csv` (transcribed by hand) |
| Our model | Evaluation metrics for the trained models | `model_metrics.json` |

## Analyses

| File | What it does |
|---|---|
| `analyses/fetch_worldbank.py` | Downloads World Bank indicators listed in `config/indicators.yaml` → `data/worldbank_*.csv` |
| `analyses/fetch_pums.py` | Downloads Census PUMS (~2.3 GB), filters to young graduates, labels the three outcomes → `data/pums_grads.parquet` |
| `analyses/train_model.py` | Trains and evaluates logistic regression and gradient boosting models, including a fairness check → `data/model_metrics.json` |
| `analyses/export_model.py` | Exports the decision trees so the model runs in the browser → `frontend/public/model.json` |
| `analyses/make_charts.py` | Makes the matplotlib charts for the website → `frontend/public/charts/*.png` |
| `analyses/ai_exposure.py` | Joins AI exposure scores to graduates' jobs → `data/ai_exposure_by_major.csv` |
| `analyses/export_game_data.py` | Builds facts and the demographic mix used by the game → `frontend/public/game_data.json` |
| `analyses/WorldBank.ipynb` | Exploratory notebook: US and Americas NEET / youth unemployment trends, OECD scatter (`fig_*.png`, `fig_oecd_neet_vs_unemp_2024.html`) |
| `analyses/census_ases.ipynb` | Exploratory notebook: defines NEET and job-search variables from CPS ASEC and looks at individual risk factors |
| `Reference.ipynb` | Earlier course notebook kept as a reference for regression diagnostics (not part of the pipeline) |

## Quick start

```bash
pip install -r requirements.txt openpyxl
# then run the analyses scripts in the order listed in analyses/README.md

cd frontend && npm install && npm start      # local site at http://localhost:4200
```

The site is deployed to GitHub Pages by `.github/workflows/deploy-pages.yml` on every push to `main`.
